# Memoria persistente Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dare a Claude Code una memoria persistente tra sessioni, a basso consumo di token.

**Architecture:** Un solo script stdlib `mem.py` legge/scrive due file JSONL nel repo (fonte di verità) e mantiene una cache SQLite FTS5 per la ricerca. Tre hook di Claude Code lo chiamano (avvio, dopo ogni tool, stop); una skill spiega a Claude come usarlo.

**Tech Stack:** Python 3 stdlib (json, sqlite3, argparse, unittest), hook di Claude Code.

**Spec:** `docs/superpowers/specs/2026-11-27-memoria-design.md`

## Global Constraints
- Solo libreria standard Python; nessuna rete, nessuna API.
- Indice di avvio ≤ 1200 caratteri (~300 token).
- Ogni sottocomando `hook-*` esce con codice 0 anche se va in errore.
- Fonte di verità: `.claude/memory/observations.jsonl`, `.claude/memory/sessions.jsonl` (committati). Cache: `.claude/memory/cache.db`, `.claude/memory/.current_session` (gitignored).
- Cartella sovrascrivibile con env `MEMORIA_DIR` (usata dai test).
- Id: 6 caratteri esadecimali.

## Review Focus
- Query con caratteri speciali FTS5 (`rates.json`, `composition-scheme 5%`, virgolette): niente eccezioni → test in Task 2.
- JSONL con una riga corrotta (merge sbagliato): la riga viene saltata, il resto funziona → test in Task 1.
- Cache vecchia dopo `git pull` che aggiunge righe ai JSONL: la cache si ricostruisce → test in Task 2.
- Stop hook in loop (`stop_hook_active: true`): non blocca mai → test in Task 4.
- Memoria vuota (primo avvio): l'indice esce con un messaggio breve, non un errore → test in Task 3.

**Interfaces — Produces:**

### Task 4: Hook

**Files:** Modify `mem.py`; Create `.claude/settings.json`; Modify `.gitignore`, `.gitattributes`

**Interfaces — Produces:**
- `auto_note(event: dict) -> dict | None` — Edit/Write/MultiEdit/NotebookEdit → `type="change"`, titolo `"Modificato <file relativo>"`; Bash → `type="command"`, titolo primi 100 caratteri; ignora Bash di sola lettura (`ls cat head tail grep rg find pwd echo which git status|log|diff|show` e chiamate a `mem.py`); altro → None.
- `stop_decision(event: dict) -> dict | None` — `{"decision":"block","reason":...}` solo se: `stop_hook_active` falso, la sessione ha note auto `change` più recenti dell'ultima nota claude/riassunto della stessa sessione.
- CLI `hook-start` (legge stdin, salva sessione, stampa indice), `hook-tool`, `hook-stop` (stampa JSON se blocca). Tutti in try/except → exit 0.
- settings.json: comando `python3 "$CLAUDE_PROJECT_DIR/.claude/skills/memoria/mem.py" <sub> 2>/dev/null || python "$CLAUDE_PROJECT_DIR/.claude/skills/memoria/mem.py" <sub>`; PostToolUse matcher `Edit|Write|MultiEdit|NotebookEdit|Bash`.
- `.gitignore` += `.claude/memory/cache.db*`, `.claude/memory/.current_session`; `.gitattributes` += `.claude/memory/*.jsonl merge=union`.
